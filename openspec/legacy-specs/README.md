# Legacy OpenSpec specs (frozen)

These files are the requirement specs written by the retired OpenSpec flow.
They are kept for reference only. They are not maintained and are not a contract.

- `specs/<capability>/spec.md` was `openspec/specs/`, the merged master copy.
- `changes/<id>/specs/` was `openspec/changes/<id>/specs/`, the per-change deltas.

Do not edit these files and do not add new ones. A change is now
`proposal.md` + `design.md` + `tasks.md` under `openspec/changes/<id>/`.
The code, its tests and the repo docs are the current contract.
When a file here disagrees with the code, the code is right.

Moved here by HARN-348 / HARN-377 (2026-10-25).
