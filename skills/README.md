# Skills Directory

This directory is intentionally empty of skill files.

Bundled skills (distributed to every new warehouse via `abc init`) live in:

```
libs/beacon/src/beacon/data/skills/<skill-name>/SKILL.md
```

That is the single source of truth. Edit skills there.

The `examples/sample-warehouse/skills/` directory reflects what `abc init` produces
and should be kept in sync with the `data/skills/` contents.
