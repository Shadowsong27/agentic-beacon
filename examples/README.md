# Examples

This directory contains example warehouses generated by `abc warehouse init` to demonstrate the Agentic Beacon framework structure.

## Contents

### sample-warehouse/
**Generated with:**
```bash
abc warehouse init sample-warehouse \
  --org "Example Corp" \
  --languages python,typescript \
  --domains data-platform,web-services
```

This shows the exact structure and placeholder content that `abc warehouse init` creates, including:
- Context file templates with instructions
- Knowledge directory structure organized by scope
- Skills directory with README
- Documentation templates
- .gitignore configuration

## Purpose

Browse this example to understand what `abc warehouse init` generates. You'll see:
- **contexts/** - Template AGENTS.md files with customization instructions
- **knowledge/** - Placeholder structure for global, language, and domain knowledge
- **skills/** - Empty directory ready for your workflows
- **docs/** - Architecture and contribution guides

## How to Use This Example

1. **Browse** - Explore the generated structure and file formats
2. **Learn** - Read the placeholder content to understand what goes where
3. **Create your own** - Run `abc warehouse init` for your organization
4. **Customize** - Replace placeholders with your actual standards

## Creating Your Own Warehouse

```bash
abc warehouse init my-org-warehouse \
  --org "Your Organization" \
  --languages python,typescript,go \
  --domains data-platform,web-services,mobile
```

Then customize the generated content for your team's needs.

## Note

This example was generated by `abc warehouse init` and contains placeholder content with instructions. It demonstrates the framework structure but is not meant to be used as-is.
