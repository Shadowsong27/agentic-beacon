## Guide vs. Design Doc

**Guides (this folder):**
- Step-by-step instructions
- Command examples
- "How do I...?" questions
- Practical workflows

**Design Docs ([docs/](../docs/)):**
- Conceptual architecture
- Design philosophy
- "Why is it designed this way?" questions
- Decision rationale
