# Agent-Assisted Setup

`abc setup --agent-assisted` is a workflow designed to help you fill in `beacon.yaml` with the help of your AI coding agent. Instead of manually browsing the warehouse to find relevant artifacts, the command generates a catalog of everything available so the agent can recommend what to include.

## When to Use This

Use agent-assisted setup when:
- You're setting up a project in an unfamiliar warehouse and don't know what artifacts exist
- You want the agent to recommend a starter set of artifacts for your project type
- You want to explore what a warehouse offers before curating `beacon.yaml` manually

Use manual setup (`abc setup --manual`) when:
- You already know exactly which artifacts you need
- You're working from a team-provided example `beacon.yaml`

---

## How It Works

```
abc setup --agent-assisted
```

This command does two things:

1. **Creates `.agentic-beacon/beacon.yaml`** — an empty template (same as `--manual`)
2. **Generates `.agentic-beacon/warehouse-catalog.md`** — a structured index of every artifact in the connected warehouse

The catalog is written as markdown and gitignored — it's a local working file you share with your agent, not something that gets committed.

---

## Step-by-Step Workflow

### Step 1: Connect and Run Setup

```bash
cd my-project
abc warehouse connect --path ~/team-warehouse
abc setup --agent-assisted
```

**Expected output:**
```
✓ Created .agentic-beacon/beacon.yaml
✓ Generated warehouse catalog: .agentic-beacon/warehouse-catalog.md

Next Steps:
  1. Share warehouse-catalog.md with your AI agent
  2. Ask the agent to populate beacon.yaml
  3. Review and edit beacon.yaml
  4. Run 'abc sync' to download artifacts
```

### Step 2: Open the Catalog

The catalog lists all knowledge files, skills, and contexts in the warehouse with their descriptions:

```
# Warehouse Catalog

## Knowledge

### knowledge/languages/python/type-hints.md
Python Type Hints

### knowledge/languages/python/async-patterns.md
Async/Await Patterns for Python

### knowledge/best-practices/tdd-workflow.md
TDD Workflow and Best Practices

## Skills

### skills/code-review/
Skill: Code Review

### skills/generate-tests/
Skill: Generate Unit Tests

## Contexts

### contexts/global.md
Organization-Wide Agent Context

### contexts/teams/backend/AGENTS.md
Backend Team Standards
```

### Step 3: Ask Your Agent to Recommend Artifacts

Open your AI coding agent in the project and prompt it to read the catalog and populate `beacon.yaml`:

**Example prompt:**
```
I'm setting up a Python FastAPI microservice. Read the warehouse catalog at
.agentic-beacon/warehouse-catalog.md and populate .agentic-beacon/beacon.yaml
with the artifacts that are relevant to this project.
```

The agent will read the catalog, understand your project context (from your codebase, `README.md`, `pyproject.toml`, etc.), and suggest a tailored `beacon.yaml`.

### Step 4: Review and Edit

Inspect what the agent produced:

```bash
cat .agentic-beacon/beacon.yaml
```

Adjust as needed — add specifics the agent missed, remove items that aren't relevant, check that paths match the warehouse structure.

### Step 5: Sync

```bash
abc sync
```

## What the Catalog Contains

The catalog is generated by scanning the warehouse and extracting descriptions from:
- The first `# Heading` in each file
- A `description:` field in YAML front-matter (if present)

Well-documented warehouse files produce more useful catalog entries. If your warehouse files use front-matter, add descriptions there:

```markdown
---
title: Python Type Hints
description: Standards for using type annotations in Python 3.11+
---

# Python Type Hints
...
```

---

## Regenerating the Catalog

The catalog is generated once and not automatically updated. If the warehouse changes, regenerate it:

```bash
abc setup --agent-assisted
```

This will overwrite `.agentic-beacon/warehouse-catalog.md` with fresh content. It will also reset `beacon.yaml` to an empty template, so run this before you've populated `beacon.yaml`, or copy your existing configuration first:

```bash
cp .agentic-beacon/beacon.yaml /tmp/beacon.yaml.bak
abc setup --agent-assisted
# Restore your previous configuration
cp /tmp/beacon.yaml.bak .agentic-beacon/beacon.yaml
```

---

## Flags

| Flag | Behavior |
|------|---------|
| `--agent-assisted` | Creates empty `beacon.yaml` + generates `warehouse-catalog.md` |
| `--manual` | Creates empty `beacon.yaml` only |
| (neither) | Interactive prompt: choose between the two modes or skip |

`--agent-assisted` and `--manual` are mutually exclusive.

---

## Files Created

| File | Committed? | Purpose |
|------|-----------|---------|
| `.agentic-beacon/beacon.yaml` | ✅ Yes | Your artifact dependencies |
| `.agentic-beacon/warehouse-catalog.md` | ❌ No (gitignored) | Working file for agent consultation |
